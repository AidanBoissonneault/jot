## Added

### Webpage capture

- Selected text: save a passage from the current webpage to the open Jottathing page.
- Source details: each passage keeps the page title and source URL with it.
- Heading capture: drag a webpage heading into the editor to save the heading with a link back to its source.

### Projects and pages

- Projects: create, rename, and archive projects for separate subjects or workstreams.
- Pages: create, rename, and archive notes inside a project.
- Navigation: switch between projects and pages from the editor header.

### Note editor

- Text blocks: use paragraphs, multiple heading levels, quotes, dividers, and code blocks.
- Lists: create bulleted lists, numbered lists, and task checklists.
- Formatting: apply bold, italic, underline, strikethrough, inline code, superscript, or subscript.
- Text appearance: adjust font size, text color, and highlight color.
- Links and media: add hyperlinks, insert images or audio by URL, and record an audio clip in the editor.
- Editing controls: undo or redo changes as you work.

### Notion sync

- Connection: connect Jottathing to Notion and choose a destination page.
- Project sync: sync projects and their pages with the connected Notion workspace.
- Local queue: keep edits in the browser and queue them for sync when the connection is unavailable.
- Conflict review: compare local and Notion versions, then choose which changes to keep.
